# chatpoc

A proof-of-concept chat application.

## Overview

This project is a chat POC exploring real-time messaging functionality.

 

## Getting Started

### Prerequisites

- Node.js (or relevant runtime)
- Package manager (npm / yarn / pnpm)

### Installation

```bash
git clone https://github.com/harish1454/chatpoc.git
cd chatpoc
npm install
```

### Running the App

```bash
npm start
```
